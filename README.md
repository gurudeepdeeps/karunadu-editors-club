## 📖 About

**Karunadu Editors Club** is a community-driven platform built by editors, for editors. We provide premium editing plugins, software, creative tools, and assets — either completely free or at the lowest possible price.

From industry-level courses to exclusive assets, our mission is simple: **Make top-tier editing resources accessible to everyone.**

---

## ✨ Features

- 🖥️ **Cross-Platform Software** - Windows & Mac editing software (Premiere Pro, After Effects, DaVinci Resolve, Final Cut Pro)
- 🔌 **Premium Plugins** - Boris FX, Red Giant, and more for Premiere Pro & After Effects
- 🧊 **Blender Addons** - Professional 3D modeling and animation tools
- 🚗 **High-Quality Assets** - Car clips, VFX packs, and SFX libraries
- 🔍 **Smart Search** - Quick command palette (⌘K / Ctrl+K)
- 📱 **Fully Responsive** - Optimized for desktop, tablet, and mobile
- ♿ **Accessible** - WCAG compliant with ARIA labels and semantic HTML
- 🌐 **SEO Optimized** - Meta tags and Open Graph for better discoverability

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Git (for cloning)
- Optional: Local web server (Live Server, Python SimpleHTTPServer, etc.)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/gurudeepdeeps/karunadu-editors-club.git
   cd karunadu-editors-club
   ```

2. **Open in browser**
   ```bash
   # Using Python 3
   python -m http.server 8000

   # Using Node.js with npx
   npx serve

   # Or simply open index.html in your browser
   ```

3. **Access the site**
   - Navigate to `http://localhost:8000` (or the port shown)
   - Or open `index.html` directly in your browser

## 🎨 Key Features Explained

### 🔍 Command Palette Search
Press `⌘K` (Mac) or `Ctrl+K` (Windows/Linux) to quickly search and navigate between pages.

### 📱 Mobile-Friendly Design
- Hamburger menu for mobile navigation
- Touch-optimized scrolling
- Responsive typography and layouts

### ♿ Accessibility First
- Semantic HTML5 elements
- ARIA labels for screen readers
- Keyboard navigation support
- Alt text on all images

### 🔒 Security
- `rel="noopener noreferrer"` on external links
- No inline scripts or eval()
- Content Security Policy ready
